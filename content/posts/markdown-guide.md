Este artículo muestra algunos ejemplos de Markdown que puedes usar.

## Encabezados

Usa `#` para encabezados:

```markdown
# Encabezado 1
## Encabezado 2
### Encabezado 3
```

## Énfasis

- **Negrita**: `**texto**`
- *Cursiva*: `*texto*`
- ~~Tachado~~: `~~texto~~`

## Enlaces

```markdown
[Texto del enlace](https://ejemplo.com)
```

## Imágenes

```markdown
![Texto alternativo](/images/ejemplo.jpg)
```

## Código

En línea: `código aquí`

Bloque:

```python
def hola():
    print("¡Hola desde Hugo!")
```

## Listas

Ordenadas:
1. Primero

3. Tercero

- Elemento uno
- Elemento dos
