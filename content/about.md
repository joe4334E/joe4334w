## :penguin: Linuxero

{{< image src="/images/about/linux-tux.png" alt="Tux el pingüino de Linux" width="200" >}}

Me gusta Linux. Mucho. Desde que descubrí que no necesitaba pagar por un sistema operativo
que además me dejaba hacer lo que quisiera con él, no hay vuelta atrás.

<!--more-->

**Distro actual:** Arch Linux ( btw uses Arch )

{{< admonition type="tip" title="¿Por qué Arch?" >}}
Porque me gusta entender qué hay debajo del capó. Si algo se rompe, aprendo a arreglarlo.
Si no se rompe, lo rompo yo para aprender a arreglarlo.
{{< /admonition >}}

**Lo que uso a diario:**
- Terminal: `zsh` + `starship`
- Editor: Neovim / VS Code
- WM: Hyprland
- Navegador: Firefox
- Shell scripts para todo
